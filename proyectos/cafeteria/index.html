☕ Cafetería institucional

Reconstrucción del ecosistema que automatiza la cafetería del banco: el proveedor publica el menú del día, el colaborador ordena desde el portal y paga con cobro electrónico o descuento por planilla, y RRHH concilia el consumo del periodo.

C# .NET ASP.NET MVC SQL Server REST API
⚠️ Demo con datos ficticios. Los colaboradores, saldos y precios son inventados; la lógica de órdenes, cobro y conciliación es la misma que implementé en producción.
