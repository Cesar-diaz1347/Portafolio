📦 Traslados de inventario inter-sucursales

Aplicación de traslados entre sucursales: valida existencias antes de autorizar el envío, mantiene la mercadería en tránsito hasta que la sucursal destino confirma la recepción y registra cada movimiento en el kardex.

SQL Server T-SQL C# .NET
⚠️ Demo con datos ficticios. Sucursales, productos y existencias son ficticios; las reglas de validación y el ciclo del traslado son las del sistema real.
